# AI 지식베이스 폴더

이 폴더에 RAG용 문서를 넣으면 앱 시작 시 자동으로 ChromaDB에 인덱싱됩니다.

## 지원 형식

- `.pdf` — 학교 공지사항, 학사 가이드, 취업 자료 등
- `.txt` — FAQ, 자주 묻는 질문 등

## 예시 파일

```
knowledge/
├── 학사안내_2024.pdf
├── 취업지원센터_FAQ.txt
├── 전공별_진로안내.pdf
└── 장학금_안내.txt
```

## 주의사항

- `chroma_db/` 폴더가 이미 존재하면 기존 인덱스를 재사용합니다
- 문서를 추가/수정한 경우 `chroma_db/` 폴더를 삭제하고 앱을 재시작하세요
