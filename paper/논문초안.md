# 대학 공식 문서 기반 RAG와 학생용 LoRA 미세조정이 한국어 학사 질의응답의 환각과 정답률에 미치는 효과 및 신뢰성 비교

⁰경북대학교 컴퓨터학부, ¹【소속】

【이메일】

## 초록 (Abstract)

대규모 언어모델(LLM) 기반 챗봇은 학사 안내 업무를 보조할 수 있지만, 학교마다 다르고 학기마다 바뀌는 학사 정보를 사전학습만으로는 알 수 없어 그럴듯한 오답, 즉 환각을 만들어 낸다. 본 연구는 경북대학교 컴퓨터학부 공지사항 3,050건과 강의계획서 81건을 수집해 BGE-M3 임베딩과 ChromaDB로 검색하는 검색 증강 생성(RAG) 시스템을 구현하였다. 또 같은 공지에서 생성한 질의응답 585쌍으로 Llama-3.1-8B-Instruct에 학생용 LoRA 어댑터를 학습시켜, 외부 문서를 검색하는 방식과 지식을 모델 가중치에 주입하는 방식을 비교하였다. 2026학년도 2학기 학사 질문 30문항에 대해 기본 모델, RAG, 학생용 LoRA, 교수자용 LoRA(대조군)의 응답을 평가자 3인이 맹검으로 평가하였다. 그 결과 RAG는 정확성을 2.00점에서 3.76점(5점 척도)으로 높였고(p<0.001), 정답 문서와 어긋나는 응답의 비율을 70%에서 13%로 줄였다. 반면 학생용 LoRA는 기본 모델과 유의한 차이가 없었다(2.04점, p=0.63). 오히려 말투만 학습되어 근거 없는 날짜·절차를 단정적으로 제시하는 사례가 관찰되었다. LLM 평가자(Claude) 점수도 인간평가와 같은 경향을 보였다(Spearman ρ=0.61~0.68). 이는 소규모 합성 데이터로 학습한 LoRA보다 공식 문서 검색이 한국어 학사 질의응답의 신뢰성 확보에 더 효과적임을 보여준다.

**키워드:** 검색 증강 생성, LoRA, 환각, 학사 질의응답, 한국어 LLM

## 1. 개요

### 1.1 문제점

대학생은 수강신청, 휴학·복학, 졸업요건, 장학금 등 학사 정보를 학과 공지사항 게시판과 첨부파일에서 직접 찾아야 한다. 경북대학교 컴퓨터학부 공지 게시판에만 3,000건이 넘는 게시글이 있다. 그 상당수는 이미지·PDF 첨부로만 정보를 담고 있어 키워드 검색으로 찾기 어렵다. 같은 종류의 공지(예: 수강변경 기간)도 학기마다 다시 게시되므로, 학생이 지난 학기 공지를 보고 잘못된 일정을 따를 위험도 있다.

LLM 기반 챗봇은 자연어 질문에 바로 답할 수 있어 대안으로 떠오르고 있다. 그러나 범용 LLM은 특정 대학·학기의 학사 정보를 학습한 적이 없다. 그래서 일반적인 대학 사례를 바탕으로 그럴듯하지만 사실과 다른 답, 즉 환각(hallucination)[3]을 생성한다. 학사 정보에서 생기는 환각은 신청 기한을 놓치거나 졸업요건을 잘못 이해하는 것처럼 학생에게 직접적인 불이익으로 이어질 수 있어 특히 치명적이다.

### 1.2 해결 방향

LLM에 도메인 지식을 넣는 대표적인 방법은 두 가지이다. 첫째, 질문할 때마다 관련 문서를 검색해 프롬프트에 넣는 검색 증강 생성(RAG)[1]. 둘째, 도메인 데이터로 모델 일부를 추가 학습하는 매개변수 효율적 미세조정(LoRA)[2]이다. 영어권 연구에서는 두 방법을 비교한 결과가 보고되었다[4][6]. 그러나 자주 바뀌는 한국어 대학 학사 정보에 대해 두 방법이 환각과 정답률에 어떤 영향을 주는지, 인간평가로 확인한 연구는 드물다.

본 연구는 실제 대학 공식 문서로 RAG 시스템과 학생용 LoRA 어댑터를 각각 구현하고, 같은 질문 세트로 다음 세 가지 연구 질문을 검증한다.

- **RQ1.** 공식 문서 기반 RAG는 기본 모델 대비 정답률을 높이고 환각을 줄이는가?
- **RQ2.** 같은 공식 문서로 만든 질의응답 데이터로 학습한 학생용 LoRA는 기본 모델 대비 정답률을 높이고 환각을 줄이는가?
- **RQ3.** 두 방법 중 어느 쪽이 더 신뢰할 수 있는 응답을 생성하며, 자동 평가(LLM 평가자)는 인간평가를 얼마나 대체할 수 있는가?

## 2. 관련연구

**검색 증강 생성.** Lewis 등[1]은 사전학습된 생성 모델에 밀집 검색기(dense retriever)를 결합한 RAG를 제안해, 지식 집약적 질의응답에서 매개변수에만 의존하는 모델보다 사실성이 높아짐을 보였다. Gao 등[12]은 이후의 RAG 연구를 정리하며, 검색 품질과 문맥 활용 방식이 성능을 좌우한다고 지적하였다. 본 연구는 다국어·한국어 검색 성능이 검증된 BGE-M3[7]를 임베딩 모델로 사용한다.

**LoRA 미세조정.** Hu 등[2]은 사전학습 가중치는 고정하고 저랭크 행렬만 학습하는 LoRA를 제안하였다. 이 방법은 적은 계산 자원으로도 도메인 적응을 가능하게 해 소규모 연구실·학부 프로젝트에서도 널리 쓰인다.

**지식 주입 방식 비교.** Ovadia 등[4]은 비지도 미세조정과 RAG를 비교하였다. 그 결과 기존 지식과 새로운 지식 모두에서 RAG가 일관되게 우세했고, 미세조정으로는 새로운 사실을 학습시키기 어렵다고 보고하였다. Soudani 등[6]도 덜 알려진 지식일수록 RAG가 미세조정보다 효과적임을 보였다. 특히 Gekhman 등[5]은 미세조정으로 새로운 지식을 주입하면 모델이 그 지식을 느리게 학습하는 반면 환각 경향은 커진다고 보고하였다. 본 연구는 이러한 선행 결과를 한국어 대학 학사 도메인에서, 인간평가를 통해 검증한다는 점에서 차이가 있다.

**환각과 평가.** Ji 등[3]은 생성 결과가 원천 정보나 사실과 맞지 않는 현상을 환각으로 정의하고 유형을 분류하였다. RAG 평가를 자동화하기 위해 RAGAS[10]가 Faithfulness, Context Precision 등의 지표를 제안하였다. Zheng 등[11]은 강력한 LLM을 평가자로 쓰는 LLM-as-a-Judge가 인간 선호와 높은 일치도를 보이지만 편향이 있음을 보고하였다. 본 연구는 인간평가를 주 지표로 삼고, LLM 평가와 RAGAS는 보조 지표로 사용한다.

## 3. 시스템 상세 설계

### 3.1 전체 구조

그림 1은 전체 시스템 구조를 보여준다. 시스템은 (1) 학사 문서 수집·전처리, (2) 벡터 검색 기반 RAG, (3) 합성 질의응답 데이터 생성과 LoRA 학습, (4) 응답 생성·평가의 네 모듈로 구성된다. RAG와 LoRA는 같은 공식 문서에서 출발하지만, 지식을 각각 검색 문맥과 모델 가중치라는 서로 다른 경로로 모델에 전달한다.

```
[그림 1] 전체 시스템 구조

 컴퓨터학부 공지(3,050건) ─┐
 강의계획서(81건) ─────────┤
                          ▼
              수집·텍스트 추출(본문, PDF, 이미지 OCR)
                          ▼
              전처리·청킹(700자, 중첩 100자)
             ┌────────────┴─────────────┐
             ▼                          ▼
   BGE-M3 임베딩 → ChromaDB      Gemini 질의응답 생성(585쌍)
             │                          ▼
   질문 → 상위 5개 청크 검색       LoRA 학습(r=16, α=32)
             ▼                          ▼
```

### 3.2 문서 수집 및 전처리

경북대학교 컴퓨터학부 공지사항 게시판에서 게시글 3,050건과 첨부파일을 수집하였다. 본문 텍스트 외에도 PDF(pypdf, PyMuPDF), 한글(HWP) 문서, 이미지(pytesseract OCR)에서 텍스트를 추출해 문서 3,538개를 만들었다. 그중 716개는 이미지 OCR에서 얻었다. 강의계획서 81건도 별도로 수집하였다. 문서는 700자 단위, 100자 중첩으로 나누어 공지 청크 5,537개, 강의계획서 청크 990개를 만들었다. 각 청크에는 제목, 게시일, URL을 메타데이터로 저장해 답변에 출처를 표시할 수 있게 하였다.

### 3.3 RAG 모듈

임베딩 모델은 BAAI/bge-m3[7]를 사용하였다. 벡터 저장소로는 ChromaDB를 공지용과 강의계획서용 두 컬렉션으로 나누어 구성하였다. 질문이 들어오면 질문을 임베딩한 뒤, 강의 관련 질문은 강의계획서 컬렉션에서, 그 밖의 질문은 두 컬렉션 모두에서 검색한다. 그런 다음 거리 기준 상위 5개 청크를 고른다. 검색된 청크는 제목·게시일·URL과 함께 프롬프트에 들어간다. 프롬프트에는 "자료에 없는 내용은 추측하지 마세요", "사용한 자료의 제목과 URL을 확인할 수 있게 하세요"와 같은 근거 기반 답변 지침을 넣었다. 생성 모델은 Llama-3.1-8B-Instruct[8]이며, 로컬 환경에서 Ollama(4비트 양자화, temperature 0.2)로 서빙하였다.

### 3.4 학생용 LoRA 모듈

RAG와 같은 공지 문서 300건을 Gemini에 입력해 학생 질문–답변 형식의 합성 데이터 585쌍을 생성하였다. 이 데이터로 Llama-3.1-8B-Instruct에 LoRA[2] 어댑터를 학습시켰다. 학습 설정은 다음과 같다. rank 16, α 32, dropout 0.05이며, 대상 모듈은 어텐션(q, k, v, o)과 MLP(gate, up, down) 투영층 전체이다. 학습률은 2×10⁻⁴, 유효 배치 크기는 16(배치 2 × 누적 8), 학습은 3 에폭, 최대 길이는 2,048 토큰이며 bf16으로 학습하였다. 비교를 위해 교수자 업무 지원용 합성 데이터 500쌍으로 같은 설정에서 학습한 교수자용 LoRA를 대조군으로 사용하였다. 대조군은 학생용 LoRA의 효과가 도메인 데이터 때문인지, 단순히 어댑터 학습 때문인지 구분하기 위한 것이다. 두 어댑터는 vLLM[9]의 멀티 LoRA 서빙으로 같은 기본 모델 위에서 실행하였다(temperature 0, 최대 768 토큰).

### 3.5 평가 설계

**평가 데이터셋.** 2026학년도 2학기 기준 학사 질문 30문항을 RAG 지식베이스의 공식 문서를 근거로 직접 작성하였다. 각 문항에는 문서 기반 정답(ground truth)을 붙였다. 표 1은 주제별 문항 구성을 보여준다. 범위 밖 질문(out-of-scope) 2문항은 지식베이스에 정답이 없어, 모델이 답변을 유보하는지 확인하기 위해 넣었다.

**[표 1] 평가 데이터셋 주제 구성**

| 주제 | 문항 수 |
|---|---|
| 교육과정·전공 | 6 |
| 졸업·학적 | 6 |
| 수강신청·학사일정 | 6 |
| 수업·학생 운영 | 6 |
| 장학·지원금 | 4 |
| 범위 밖(답변 유보) | 2 |
| 합계 | 30 |

**비교 조건.** (1) 기본 모델(Base), (2) Base + RAG, (3) Base + 학생용 LoRA, (4) Base + 교수자용 LoRA의 4조건을 비교하였다. RAG를 쓰지 않는 조건에는 "모르는 내용은 추측하지 마세요"라는 공통 시스템 프롬프트를 주었다.

**인간평가.** 평가자 3인이 조건명을 가린 상태(A~E)에서 응답을 읽고, 정답과 비교해 정확성, 유창성, 간결성, 전반적 유용성을 1~5점으로 평가하였다. 본 연구에서 **환각은 "공식 문서 기반 정답과 사실이 어긋나는 응답"으로 정의**하고, 문항별 평가자 평균 정확성이 2점 이하인 응답의 비율(환각률)로 측정하였다. 평가자 간 신뢰도는 2차 가중 카파(QWK)[15]로 계산하였다.

**자동 평가.** 보조 지표로 Claude(claude-sonnet-5-5)를 평가자로 써서 같은 항목과 환각 여부를 채점하였다[11]. RAG 응답에는 RAGAS[10]의 Faithfulness와 Context Precision, 모든 응답에는 정답 대비 ROUGE-L[13]을 계산하였다.

**통계 검정.** 같은 문항에 대한 조건 간 점수 차이를 대응표본 Wilcoxon 부호순위 검정과 대응표본 t-검정으로 비교하였다. 다중 비교는 Holm 방법[14]으로 보정하고, 효과크기로 Cohen의 dz를 보고한다.

## 4. 시스템 구현 결과

### 4.1 인간평가 결과 (RQ1, RQ2)

표 2는 조건별 인간평가 점수와 환각률을 보여준다.

**[표 2] 조건별 인간평가 결과 (5점 척도, 평균±표준편차, 문항 n=30)**

| 조건 | 정확성 | 전반적 유용성 | 간결성 | 유창성 | 환각률 |
|---|---|---|---|---|---|
| Base | 2.00±1.17 | 2.09±1.07 | 2.58±0.95 | 3.32±0.85 | 70% |
| Base + RAG | **3.76±1.34** | **3.58±1.19** | **3.70±1.20** | 3.51±1.02 | **13%** |
| Base + 학생용 LoRA | 2.04±1.31 | 2.09±1.15 | 3.28±1.12 | 3.14±1.03 | 63% |
| Base + 교수자용 LoRA | 2.10±1.28 | 2.09±1.12 | 1.92±1.01 | 2.87±1.36 | 60% |

※ 평가자 단위 응답 점수의 평균. 환각률은 문항별 평가자 평균 정확성 ≤2인 응답의 비율.

표 3은 사전에 정한 비교에 대한 검정 결과를 보여준다. RAG는 기본 모델보다 정확성이 평균 1.76점 높았다(p<0.001, dz=1.05). 학생용 LoRA는 기본 모델과 차이가 거의 없었다(+0.04점, p=0.63). 교수자용 LoRA 대조군도 기본 모델과 유의한 차이가 없었다. 따라서 RQ1은 지지되고, RQ2는 지지되지 않았다.

**[표 3] 인간평가 정확성 대응 비교 (문항 n=30)**

| 비교 | 평균차 | Cohen's dz | Wilcoxon p |
|---|---|---|---|
| RAG − Base | +1.76 | 1.05 | <0.001 |
| 학생용 LoRA − Base | +0.04 | 0.03 | 0.63 |
| 교수자용 LoRA − Base | +0.10 | 0.08 | 0.56 |
| RAG − 학생용 LoRA | +1.71 | 1.36 | <0.001 |

### 4.2 자동 평가 결과

표 4는 Claude 평가자와 자동 지표의 결과를 보여준다. 인간평가와 마찬가지로 RAG만 모든 지표에서 크게 향상되었다(정확성 +1.53, Holm 보정 p<0.001). 학생용 LoRA는 기본 모델과 유의한 차이가 없었다(정확성 −0.20, Holm 보정 p=0.35). RAG 응답의 RAGAS Faithfulness는 0.88로, 생성된 주장의 대부분이 검색 문맥으로 뒷받침되었다. 한편 Context Precision은 0.60(중앙값 0.75)이었다. 즉 검색된 문맥의 상당 부분이 질문과 무관한 경우도 있었다.

|---|---|---|---|---|---|---|
| Base | 1.40 | 1.37 | 1.33 | 87% | 0.23 | – |
| Base + RAG | **2.93** | **3.17** | **2.47** | **37%** | **0.32** | 0.88 |

### 4.3 신뢰성 분석 (RQ3)

**오류 양상.** 정확성이 낮은 응답을 살펴보면 조건마다 틀리는 방식이 달랐다. 기본 모델은 일부 문항(예: 휴학 신청 기간, 등록금 납부 일정)에서 "정확히 알려드릴 수 없습니다"라며 답을 유보하였다. 반면 학생용 LoRA는 같은 유형의 질문에 존재하지 않는 날짜("2026.5.11.(월)~5.13.(수)")나 신청 조건, 시스템 메뉴 경로를 단정적으로 제시하였다. 이는 LoRA가 학습 데이터의 구체적인 사실보다 "날짜와 절차를 자신 있게 안내하는" 답변 형식을 학습했음을 시사한다. 미세조정으로 새로운 지식을 주입하면 환각이 커질 수 있다는 Gekhman 등[5]의 보고와도 일치한다. 학생 입장에서는 유보하는 답보다 확신에 찬 오답이 더 위험하므로, 정확성 점수가 비슷하더라도 학생용 LoRA의 신뢰성은 기본 모델보다 낮다고 볼 수 있다.

【선택 보완: 정확성 ≤2 응답을 ① 사실 날조 ② 답변 유보 ③ 부분 누락으로 분류한 표를 추가하면 이 문단의 근거가 정량화됨】

**범위 밖 질문.** 지식베이스에 정답이 없는 2문항에서는 기본 모델이 적절히 답변을 유보해 높은 점수(4.00, 4.67)를 받았다. 반면 RAG는 두 문항 모두 낮은 점수(1.33, 2.00)를 받았다. 예를 들어 2학기 일정을 묻는 질문에 검색된 1학기 공지를 근거로 답하였다. 이는 RAG가 검색 결과가 질문과 맞지 않을 때에도 그 문서에 근거해 답을 만들어 낸다는 한계를 보여준다. 다만 2문항뿐이므로 일반화하려면 추가 검증이 필요하다.

**평가 신뢰도.** 평가자 간 QWK는 정확성 0.52~0.63, 전반적 유용성 0.46~0.55로 중간 수준의 일치도를 보였다. 반면 유창성은 −0.18~0.19로 사실상 일치하지 않아, 유창성 점수는 해석에서 제외하였다. Claude 평가자 점수와 인간평가 평균은 정확성 ρ=0.61, 전체 점수 ρ=0.68(p<0.001, 120개 응답)로 상관이 높았고, 조건 간 순위도 같았다. 다만 Claude 평가자는 인간평가에서 정답으로 판단된 응답 62개 중 40개를 환각으로 판정해 환각을 과대 판정하는 경향을 보였다. 따라서 LLM 평가자는 조건 간 상대 비교에는 쓸 수 있지만, 환각률의 절댓값을 추정하는 데는 인간평가를 대체하기 어렵다.

### 4.4 응답 지연시간

중앙값 기준 생성 시간은 Base 5.0초, 학생용 LoRA 6.3초, 교수자용 LoRA 22.7초, RAG 41.4초였다. RAG만 다른 서빙 환경(로컬 Ollama)에서 실행되었으므로 이 지연시간은 방법 간 비교가 아닌 참고값이다.

### 4.5 연구의 한계

첫째, RAG 조건은 vLLM 대신 Ollama(4비트 양자화)에서, 검색 문맥과 답변 지침이 포함된 별도 프롬프트로 생성되었다. 따라서 본 연구의 RAG 효과는 "검색 문서"만의 효과가 아니라 "검색과 프롬프트를 포함한 RAG 시스템 전체"의 효과로 해석해야 한다. 둘째, 평가 문항이 지식베이스 문서를 근거로 작성되어 모든 문항(범위 밖 2문항 제외)의 정답이 검색 대상에 있다. 따라서 실제 사용 환경보다 RAG에 유리한 조건이다. 셋째, 문항 수(30)와 평가자 수(3)가 적고, 평가자가 연구팀 구성원이었다. 또 한 평가자는 교수자용 LoRA 조건을 평가하지 않았다. 넷째, RAG와 LoRA를 결합한 조건은 이번 연구에서 다루지 않았다.

## 5. 결론

본 연구는 경북대학교 컴퓨터학부 공지사항 3,050건과 강의계획서 81건으로 BGE-M3·ChromaDB 기반 RAG 시스템을 구현하였다. 또 같은 문서에서 생성한 585쌍의 질의응답으로 학생용 LoRA 어댑터를 학습시켜, 두 지식 주입 방식이 한국어 학사 질의응답에 미치는 영향을 인간평가로 비교하였다.

개요에서 제시한 문제, 즉 범용 LLM이 대학 학사 정보에 대해 환각을 일으키는 문제에 대해 공식 문서 기반 RAG는 뚜렷한 개선 효과를 보였다. 기본 모델은 응답의 70%가 공식 문서와 어긋났지만, RAG를 적용하자 이 비율이 13%로 줄었고 정확성은 2.00점에서 3.76점으로 높아졌다. 반면 같은 문서로 만든 소규모 합성 데이터로 학습한 LoRA는 정답률을 높이지 못했다. 오히려 근거 없는 날짜·절차를 단정적으로 제시해 신뢰성 측면에서 더 위험한 오류를 보였다. 이는 학기마다 바뀌는 학사 정보처럼 갱신이 잦은 지식에는 모델 가중치에 지식을 주입하기보다, 공식 문서를 검색해 근거로 제시하는 방식이 적합함을 보여준다. 또 LLM 평가자는 조건 간 비교에서 인간평가와 높은 상관을 보여 반복 실험의 보조 도구로 활용할 수 있었다. 다만 환각률 추정에는 인간평가가 필요하였다.

향후 연구로는 (1) 모든 조건을 같은 서빙 환경과 프롬프트에서 다시 생성해 검색 문서만의 효과를 분리하고, (2) 범위 밖 질문을 늘려 RAG의 답변 유보 능력을 검증하며, (3) RAG와 LoRA를 결합한 조건과 검색 실패 시 답변을 유보하는 전략을 평가할 계획이다.
