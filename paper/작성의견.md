# 논문 작성 의견 (2026-11-03 기준)

`논문초안.md`를 작성하면서 내린 판단과, 제출 전에 확인할 사항을 정리했습니다.

## 1. 종합 판단

현재 데이터로 **학부생 논문을 쓰는 것은 가능**합니다. 결론을 뒷받침하는 결과가 인간평가와 LLM 평가 양쪽에서 일관되게 나왔습니다.

- **RAG 효과:** 정확성 +1.76점(p<0.001), 환각률 70% → 13%
- **학생용 LoRA:** 기본 모델과 유의한 차이 없음
- **LLM 평가와 인간평가의 상관:** ρ=0.61~0.68

초안에서는 앞서 논의한 대로 다음과 같이 범위를 정했습니다.

- **RAG+LoRA 결합 조건 제외:** RQ를 RAG 효과, LoRA 효과, 두 방법 비교의 3개로 구성했습니다.
- **환각 정의:** "공식 문서 기반 정답과 사실이 어긋남 = 인간평가 정확성 ≤2"로 정했습니다. 정답을 RAG 문서로 만들었으므로 정확성 점수에 환각이 반영된다는 논리입니다.
- **RAG 효과의 해석 범위:** "검색과 프롬프트를 포함한 RAG 시스템 전체의 효과"로 좁히고, 한계(4.5절)에 서빙 환경 차이를 적었습니다.
- **유창성:** 평가자 간 일치도가 없어서(QWK −0.18~0.19) 해석에서 제외했습니다.

## 2. 제출 전 반드시 할 것

1. **【 】 부분 채우기:** 저자, 교신저자, 소속, 이메일, 위밋 사사문구, 그림 1 이미지
2. **국내 참고문헌 2~3편 추가:** 양식에서 Google Scholar 검색을 요구합니다.
3. **참고문헌 서지 확인:** 영문 참고문헌 15편은 널리 인용되는 실제 논문입니다. 다만 권·호·페이지는 Google Scholar에서 한 번 대조해 주세요.
4. **평가자 이름 익명화:** 논문, 부록, 공개 데이터에 실명을 쓰지 말고 R1~R3으로 표기하세요.
5. **지도교수 확인:** 양식에 따라 제출 1주일 전까지 이메일로 확인을 받으세요.

## 3. 시간이 있으면 하면 좋은 것 (효과 큰 순서)

1. **정확성 ≤2 응답 오류 유형 분류 (약 60건, 반나절):** ① 사실 날조 ② 답변 유보 ③ 부분 누락으로 나눕니다. 4.3절의 "LoRA는 자신 있게 틀린다"는 주장을 정량 근거로 바꿔 주고, 제목의 '신뢰성 비교'를 가장 직접적으로 뒷받침합니다.
2. **Base+RAG를 vLLM·같은 프롬프트로 다시 생성하고 재평가:** 리뷰에서 가장 먼저 지적받을 약점(서빙 환경 차이)이 없어집니다. 그러면 한계 1번과 "시스템 전체 효과"라는 단서를 뺄 수 있습니다.
3. **범위 밖 질문 8~10개로 확대:** "RAG는 문서가 맞지 않아도 그 문서로 답을 지어낸다"는 결과를 일화가 아닌 주요 결과로 쓸 수 있습니다.
4. **빠진 평가 채우기:** 평가자 R(박혁진)의 교수자용 LoRA 30건 평가를 채우면 평가 설계가 균형을 이루고 Fleiss' κ도 계산할 수 있습니다.
5. **평가 데이터셋 메타데이터 정리:** `student_eval_dataset.json`의 `source_verification` 필드에 근거 문서 URL과 게시일을 기록하세요. 지금은 `pending` 상태입니다.

주의할 점이 세 가지 있습니다.

- **학습 설정 확인 필요:** LoRA의 에폭·학습률은 스크립트 기본값입니다. 실제 학습 때 다른 값을 썼다면 3.4절을 고쳐야 합니다.
- **Claude 점수는 재실행마다 조금씩 달라짐:** 새 모델은 temperature를 고정할 수 없어서, 실행할 때마다 소수점 둘째 자리 정도가 바뀝니다. 논문에는 이번 실행 결과를 고정해서 쓰세요.
- **LoRA 대조 비교 표기:** 표 3의 LoRA 비교 p값은 보정 전 값입니다. 비교가 4개라 Holm 보정을 해도 결론은 같습니다.
